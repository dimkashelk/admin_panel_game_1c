# Администрирование экономической игры на 1С

Проект приложения на **1С:Предприятие.Элемент 10.0** для проведения учебной игры в 1С:ERP. Приложение помогает ведущему подготовить игру, управлять раундами, рассчитывать внешний рынок и сравнивать результаты команд.

Репозиторий: `admin_panel_game_1c`. Рабочая ветка: `dev`.

## Основной игровой процесс

Команды работают в ERP: устанавливают цены, планируют продажи и производство, закупают комплектующие, выпускают велосипеды и отгружают продукцию. Элемент получает данные, определяет заказы рынка и сообщает ERP о переходах между фазами.

Продукция: CityRide, SportDrive, CargoMax и TourPro.

Первоначальная продажа стартовых запасов даёт деньги на закупки. Затем повторяются планирование, закупки, производство, продажи и анализ с закрытием месяца. Этот порядок взят за основу из подробного Excel-сценария; остальные расхождения материалов перечислены в плане реализации.

ERP является источником фактических остатков, отгрузок и денег. Расчётная выручка рынка не заменяет оплату в ERP. Итоговый рейтинг строится по подтверждённым денежным остаткам после завершения всех операций раунда.

## Следующий этап

Подключить расширение ERP и выполнить интеграционный проход: служебные привязки, авторизованные запросы, конкурентные переходы, повторы, реализации/оплаты, пауза и итог месяца. Обычная игра запускается после подтверждения prepare_game всеми командами. Серверная сторона опубликована; запись исправленного исторического итога и реальные соответствия ERP ещё требуют проверки совместно с расширением.

Настройка учебной ERP через OData без расширения описана в [руководстве](docs/odata-setup.md).
