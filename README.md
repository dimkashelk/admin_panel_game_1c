# Администрирование экономической игры на 1С

Приложение на **1С:Предприятие.Элемент 10.0** для проведения учебной игры в 1С:ERP. Исходники находятся в `dimkashelk/Игра`.

Ведущий создаёт игру, настраивает сценарий, команды, пользователей и подключения ERP, управляет фазами и публикует рейтинг. Игроки работают в своих ERP и получают заказы через кабинет. ERP служит источником фактических остатков, продаж, оплат и денег.

Реализованы серверные ограничения и права, версионирование сценариев, подготовка игры, два алгоритма распределения рынка, общий пул заказов, пульт ведущего, HTTP-контракт ERP 1.0, настройка баз через OData, диагностика обмена, сверка периодов и результаты команд.

Подготовка и переходы между фазами требуют подтверждений ERP. Рейтинг строится по подтверждённым денежным остаткам. Расчётная выручка рынка не заменяет фактические оплаты.

## Служебные инструменты

`scripts/setup_erp_odata.py` подготавливает базу ERP; `scripts/read_erp_market.py` читает цены и остатки. `scripts/generate_game_contract.py` создаёт контракт и модуль схем по нормативным таблицам; `scripts/generate_odata_setup_profile.py` создаёт модуль профиля OData. Скрипты используют стандартную библиотеку Python 3.
