# Создание игры и настройка сохранённой игры

В меню есть два отдельных сценария: **«Новая игра»** создаёт игру, **«Настройка игры»** редактирует существующую. Из пульта кнопка **«Настройка этой игры»** открывает настройки выбранной игры. На этих формах и в окне настройки команды нет сворачиваемых блоков.

## Новая игра

1. Укажите название и выберите сценарий. Seed и режим общего рынка находятся в общей группе правил. По умолчанию Seed = 42 и включён общий рынок.
2. В таблице уже есть **«Команда 1»** и **«Команда 2»**. Переименуйте их, добавьте или удалите строки стандартными командами таблицы. Требуется минимум две команды с уникальными названиями.
3. При необходимости откройте **«Настроить команду»** карандашом в строке. Игроки и ERP не обязательны для создания игры.
4. Нажмите **«Создать игру»**. Игра, команды, назначения игроков и подключения записываются в одной транзакции. После успеха открывается отдельная форма настройки созданной игры. При ошибке черновики остаются для исправления.

Столбец **«Игроков»** доступен только для чтения. Значение обновляется по фактическому составу команды после нажатия **«Готово»** в её настройках.

## Существующая игра

Выберите игру в разделе **«Настройка игры»**. Правила, добавление и переименование команд доступны администратору до подготовки игры. Правила сохраняются кнопкой **«Сохранить настройки игры»**. Выберите команду и откройте **«Настроить команду»** для изменения её игроков и ERP.

Права ведущих и наблюдателей, профиль ERP, сервисные привязки и соответствия номенклатуры доступны через **«Открыть расширенные настройки игры»**. Переход к пульту выполняется отдельной кнопкой; настройки не запускают игру автоматически.

## Игроки команды

Вкладка **«Игроки команды»** содержит редактируемую таблицу активных игроков. Добавляйте строку стандартной командой таблицы и выбирайте пользователя в ячейке. Удаляйте выбранные строки стандартной командой удаления. Пустые строки и повтор одного пользователя не допускаются.

Изменения таблицы применяются по общей основной кнопке **«Готово»**. Для сохранённой игры удаление строки отключает назначение пользователя в этой команде, сохраняя его назначения в других командах. Для новой игры состав сохраняется в черновике команды и записывается при создании игры. Закрытие крестиком отменяет несохранённые изменения таблицы и параметров ERP.

После создания игры можно отдельно создать нового пользователя: укажите логин и временный пароль либо оставьте пароль пустым для генерации. **«Создать игрока и добавить в команду»** сразу создаёт пользователя и назначает его выбранной команде; это отдельное действие не отменяется закрытием формы. Выданный пароль показывается в маскированном поле. При первом входе игрок меняет временный пароль.

Создание игр, изменение состава и управление пользователями доступны администратору. Ведущий может настраивать ERP своей игры без изменения списка игроков.

## База ERP команды

1. Введите **адрес публикации ERP**, затем **логин** и **пароль**. Полный адрес OData формируется автоматически добавлением `/odata/standard.odata/`.
2. После изменения пароля система загружает доступные организации. Для повторной загрузки есть кнопка **«Загрузить организации»**. Список читается из ERP, с учётом прав указанного пользователя, без помеченных на удаление организаций и с постраничным чтением.
3. Выберите организацию из списка. Произвольный ввод запрещён. Если организация одна, она выбирается автоматически. Изменение адреса или логина очищает прежний список и выбор.
4. Нажмите общую кнопку **«Готово»**, чтобы сохранить ERP вместе с составом команды. Отдельной кнопки сохранения базы нет. При ошибке окно остаётся открытым, введённые данные сохраняются для исправления.

В сохранённой команде показывается адрес публикации без OData-суффикса. Сохранённый пароль не возвращается на клиент: пустое поле сохраняет его при неизменном адресе и логине. Для получения организаций сервер использует сохранённый секрет. При изменении адреса или логина требуется новый пароль. Неизменное сохранённое подключение позволяет записать изменения состава даже при недоступной ERP.

Каждая команда игры использует отдельный адрес ERP. После подготовки адрес и организацию менять нельзя. Кнопка **«Подготовить или проверить базу»** работает с уже сохранённым подключением; новые параметры сначала запишите через **«Готово»**. Полный цикл игры по-прежнему требует расширения обмена ERP.
