# Интерфейс приложения

Рабочее место Элемента ориентировано на ведущего и администратора. Студенты выполняют учебные действия в ERP. Технические детали обмена показываются на странице диагностики; основной игровой экран объясняет состояние команды и необходимое действие.

## Навигация

Главная → Игры → Пульт выбранной игры. Отдельные разделы: Сценарии, Номенклатура, Подключения ERP, Результаты. Пользователь видит только доступные ему разделы и игры.

| Экран | Основные данные | Действия |
|---|---|---|
| ГлавнаяСтраница | Идущие игры, текущие фазы, команды с проблемами | Открыть игру, создать игру, открыть сценарии |
| ИгрыФормаСписка | Название, ведущий, статус, раунд, участники, время | Создать, открыть настройки, открыть пульт |
| МастерНовойИгры | Сценарий, число раундов, участники, подключения, начальные условия | Проверить, подготовить базы, получить контрольные снимки |
| ПультВедущего | Фаза, оставшееся время, готовность, продажи, связь с ERP | Зафиксировать фазу, выполнить следующий допустимый шаг, пауза, возобновление |
| СценарииИгрыФормаОбъекта | Алгоритм, спрос, цены, сроки, тренды, стартовые ресурсы | Сохранить черновик, создать новую версию, проверить рынок |
| ПроверкаРынка | Тестовые цены и количества, распределение и расчётная выручка | Пересчитать предварительно, сравнить два алгоритма |
| ПодключенияERPФормаОбъекта | База, режим, соответствия, возможности, последнее успешное чтение | Проверить доступ, загрузить метаданные, сопоставить номенклатуру |
| РезультатыИгры | Деньги, рейтинг, прибыль, продажи, доли рынка, запасы | Выбрать раунд, сравнить команды, открыть историю |
| ДиагностикаОбмена | Сообщения, команды, ошибки, внешние GUID | Повторить безопасную доставку, посмотреть причину |

## Пульт ведущего

```text
Игра «Производство велосипедов»        Раунд 2 из 4        Идёт
Планирование → Закупки → Производство → Продажи → Анализ

Текущая фаза: Производство              Осталось 08:35
Готовы 3 из 4 команд                     Ожидаем команду «Вектор»

Команда       Готовность   Данные ERP     Выпуск ГП    Причина ожидания
Альфа         Готова       12:04:10       30 шт        —
Вектор        Работает     12:04:08       18 шт        Заказ не завершён
Гамма         Готова       12:04:11       24 шт        —
Дельта        Готова       12:04:09       22 шт        —

[Зафиксировать фазу] [Пауза] [Открыть результаты]
```

Это схема расположения, не работающий интерфейс. В реальной форме под каждой проблемной командой показывается конкретная причина: нет связи, не подтверждён снимок, отсутствует цена или не закрыт документ.

Кнопка перехода не скрывает незавершённый обмен. Если участник исключается из раунда, ведущий видит последствия и вводит причину. Исправление рассчитанных и уже отправленных заказов выполняется отдельной командой, а не редактированием табличной строки.

## Мастер новой игры

1. Выбрать сценарий и его версию. Показать правила оценки и алгоритм рынка.
2. Добавить участников и выбрать их базы или области ERP. Проверить отсутствие пересечений с идущими играми.
3. Проверить опубликованные возможности обмена и соответствия всех продуктов.
4. Сгенерировать начальные ресурсы один раз по seed и показать одинаковый набор для всех команд.
5. Подготовить ERP и сравнить её контрольные снимки с заданным набором.
6. Начать стартовую продажу после успешного подтверждения всех участников.

Мастер может быть закрыт и продолжен: состояние подготовки сохранено. Повтор кнопки не создаёт новые начальные остатки.

## Настройки сценария

Разделы формы: Общие, Рынок, Начальные условия, Фазы и сроки, Тренды раундов. На странице Рынок — четыре строки продукции и понятные подписи коэффициентов. При выборе алгоритма объясняется распределение спроса; переключение не изменяет параметры молча.

Проверка рынка работает с копией входа. На экране явно написано «Предварительный расчёт»: он не создаёт заказы ERP и не изменяет текущую игру. Аналитическая графика показывает цену и проданное количество, если она помогает сравнить стратегии.

Редактирование использованного сценария заменяется действием «Создать новую версию». Во время игры настройки только читаются.

## Результаты

Главный столбец рейтинга — подтверждённые деньги на конец раунда. Расчётный заказ, фактическая отгрузка и оплата показываются отдельными столбцами. Неподтверждённые данные не выглядят как нулевой результат.

На вкладках: Рейтинг, Продажи по моделям, Деньги и прибыль, Остатки, История. Стартовая продажа отображается как раунд 0 отдельно от производственных раундов. Наблюдатель видит только опубликованные показатели; цены и запасы текущей незавершённой фазы ему недоступны.

## Компоненты Элемента 10

- Независимая `Форма` для главной страницы и пульта, объектные формы для справочников.
- `СтандартнаяКарточка` для игры и кратких показателей, таблицы и динамические списки для сравнения команд.
- `ПанельЭтапов<ФазыИгры>` для фазы. Стартовая продажа отображается отдельно; порядок производственных фаз задаётся явно, а не берётся из полного перечисления автоматически.
- Страницы и группы для настроек и результатов. Канбан не требуется для основного пульта.

Пользовательские формы имеют `ВключатьВАвтоИнтерфейс: Ложь`, объект ссылается на созданные формы в своей секции `Интерфейс`. Для списка используются реальные типы и namespace из `xbsl-form-info`; ссылки на несуществующие поля не генерируются.

Пульт рассчитан на широкий экран. На узком экране первая информация — фаза, время, готовность и основное действие; таблицы доступны с прокруткой. Ошибки объясняются текстом и не зависят только от цвета.
